「搞字体设计，那得多酷啊！笔画一拉，衬线一加，国际范儿就上来了！」

相信很多人和我一样，在某一天突然想要入手字体设计，领略文字字形之美，于是开始寻找适合上手的字体设计软件。

上网一搜「字体设计用啥软件」，映入眼帘的便是清一色的推荐 Glyphs，毕竟 Glyphs 一度被视为行业标杆，甚至被誉为设计师的圣杯。

然而令人遗憾的是，Glyphs 软件只能在 Mac 上使用，这对普遍使用 Windows 的用户而言极其不友好。

在 2022 年 8 月 4 日，Glyphs 官方发表了一篇文章，名为[《为什么 Glyphs 没有 Windows 版》](https://glyphsapp.com/zh/learn/why-there-is-no-windows-version-of-glyphs)，解释了 Glyphs 一直以来只推出 Mac 版而不推出 Windows 版的原因。作为一名业余字体爱好者，当我好奇其原因，点开这篇声明，以为能看到技术壁垒、开发难度等客观理由时，却只看到了一场充满优越感的「凡尔赛式」炫耀，字里行间的傲慢与偏见，像一根刺，狠狠扎在每一个渴望公平的设计师和业余字体爱好者的心上。

![Glyphs 官网《为什么 Glyphs 没有 Windows 版》原文](https://raw.githubusercontent.com/Des-Magmeta/des-magmeta.github.io/main/src/content/posts/2026-03-06/zh-hans/glyphs-no-windows_zh-hans.jpeg)  

声明里那些看似冠冕堂皇的理由，在 Windows 用户眼中更像是敷衍的借口。「虽然我们通常并不拒绝跨平台，但在现阶段而言，涉足 Windows 在经济上并不可行。」官方这一声明在本人看来显然荒谬。众所周知，全球 PC 市场 80% 以上的份额被 Windows 占据，其使用量明显高于 Mac，按照官方假设「每一份请求都转化为一份正版销售」，理应赚得盆满钵满。官方竟声称此类情形下「销售额也无法抵扣开发和支持的额外开销」「我们必须投资个六位数来换取每年几百美元的预期收入」，明显更像是对市场需求的刻意漠视，对用户选择的粗暴否定。

此外，稍微了解行业的人都清楚，如今跨平台开发早已不是什么天方夜谭。从设计软件到办公套件，无数产品都实现了 Windows 与 Mac 系统的完美兼容。而在一系列字体设计软件中，FontCreator 官方 High-Logic 于 2024 年 9 月[宣布已经支持 Mac 版](https://www.high-logic.com/zh/news/fontcreator-for-macos-released)（此前仅支持 Windows 版）。对比之下，Glyphs 至今仍没有 Windows 版，这对想用 Glyphs 的 Windows 用户而言，无疑是一种难以弥补的遗憾。

![FontCreator 官方于 2024 年 9 月宣布已经支持 Mac 版](https://raw.githubusercontent.com/Des-Magmeta/des-magmeta.github.io/main/src/content/posts/2026-03-06/fontcreator-supports-mac.jpeg)  

为何偏偏 Glyphs 就爱搞「特殊」？说到底，不过是骨子里的傲慢在作祟。在文中，他们甚至引以为傲地宣称「字体设计是一项 Mac 的活计」，可当我们看到 Windows 用户正在使用 FontCreator、FontLab、FontForge 等软件制作字体时，你就会发现这话背后透露着 Glyphs 官方一股傲慢的气息。Mac 似乎已经成为了 Glyphs 官方的精神图腾和皈依，宁愿蜷缩在 Mac 用户的小圈子里，享受着「精英工具」的虚假光环，也不愿放下身段服务使用 Windows 进行设计的爱好者和设计师，仿佛 Windows 用户就不配踏入高端字体设计的大门。这种将用户群体进行「等级划分」的做法，不仅是对 Windows 用户选择的粗暴否定，更是暴露出 Glyphs 既想赚「苹果人」的钱，又不想承担服务大众的责任，可以说是**典型的又当又立**。

或许在看到标题的那一瞬间，一些正持有 Mac、用着 Glyphs 的用户在脑中就已经开始对我的想法产生疑问。「既然 Glyphs 没有 Windows 版，为什么不用别的软件？」从鄙人的观点看，每个软件都有各自的特点，势必会有一些特色功能其他软件无法实现（或是没有相同的体验感），这并非靠简单更换成别的软件就能解决的。

不可否认，Glyphs 在 Mac 平台上确实取得了不错的成绩，凭借其强大的功能和「智能部件」等便于高效编辑的特色，收获了一众用户。但这绝不是它能忽视 Windows 用户的理由。毕竟全球 PC 市场中，Windows 系统占据着绝对的主导地位，其中不乏大量热爱字体设计、渴望专业工具的爱好者。他们或许是刚入行的新手，怀揣着对字体设计的热情，却因 Glyphs 的「系统歧视」，只能望洋兴叹；他们或许是经验丰富的设计师，习惯了 Windows 系统的操作逻辑，却不得不为了一款软件，被迫更换设备，增加额外的成本。这对于广大 Windows 用户来说，无疑是一种不公平的待遇。至于 Glyphs 官方说的「为每位需要 Windows 版本的人分发一台 Mac，要比实际开发和管理 Windows 版本软件还要便宜得多」这一黑白颠倒的论述，只不过是为他们骨子里对 Windows 用户的傲慢掩盖一层遮羞布罢了。

正如标题所说，看完 Glyphs 官方的说明后，作为一名用着 Windows 系统，想用 Glyphs 却无缘接触的业余字体爱好者，本人实在无法认同。与其说是解释，倒不如说是「狡辩」，想必应该有许多设计师／爱好者和我一样，对 Glyphs 这类行径「永远无法原谅」吧？Glyphs 的这种做法，不仅寒了 Windows 用户的心，也在拖整个字体设计行业的后腿。字体设计本应是一个开放、包容的领域，不同的系统、不同的工具都应该有其价值。可 Glyphs 却人为设置门槛，将 Windows 用户挡在门外，也把自己困在了 Mac 的小圈子里。这种短视的行为，只会让字体设计圈变得越来越封闭，最终阻碍整个行业的创新与进步。

对于想要入手字体设计的 Windows 用户来说，Glyphs 的「缺席」是一种难以弥补的遗憾。我们只能在功能单一的工具中艰难抉择，或者咬牙花大价钱购买 Mac 设备。大多数人应该和我一样，选择了前者，在各异的软件中艰难前行。这种无奈与失落，Glyphs 永远不会懂。我不禁要质问 Glyphs 官方：**你们的傲慢还要持续多久？什么时候才能放下身段，真正倾听用户的声音，为 Windows 用户带来一款同样优秀的字体设计工具？**

字体设计的魅力，在于它能跨越界限展示文字之美，传递情感与思想。这种魅力，不该被操作系统的壁垒所束缚。我在此奉劝 Glyphs 能早日醒悟，打破「系统歧视」的枷锁，以开放包容的姿态迎接每一位热爱字体设计的创作者。毕竟，只有让更多人参与进来，字体设计行业才能真正焕发生机。

~~只要 Glyphs 一日不打算开发 Windows 版，我就永远无法原谅《为什么 Glyphs 没有 Windows 版》！~~
