「フォントデザインって、なんてカッコいいんだろう！筆画を一本引く、セリフを一つ加えるだけで、国際的な雰囲気が一気にアップするんだ！」

きっと多くの人も私と同じように、ある日突然フォントデザインを始めたいと思い、文字の字形の美しさを味わおうと、初心者向けのフォントデザインソフトを探し始めることでしょう。

ネットで「フォントデザインに使うソフト」と検索すると、目に入るのはほぼ例外なく Glyphs の推奨ばかり。何しろ Glyphs は業界の標準と見なされ、デザイナーの聖杯とまで称賛されてきたからだ。

しかし残念なことに、Glyphs は Mac でしか使えず、Windows ユーザーには非常に不親切な仕様だ。

2022 年８月４日、Glyphs 公式は[『なぜ Glyphs には Windows 版がないのか』](https://glyphsapp.com/learn/why-there-is-no-windows-version-of-glyphs)と題した記事を発表し、これまで Mac 版のみを提供し Windows 版をリリースしなかった理由を説明した。アマチュアのフォント愛好家として、その理由を知りたくてこの声明を開いた私は、技術的な障壁や開発の難しさといった客観的な理由が書かれていると思っていた。ところがそこにあったのは、優越感に満ちた「ヴァルセ式」の自慢話だけだった。行間からにじむ傲慢と偏見は、公平さを求めるデザイナーやアマチュアフォント愛好家の心に、棘のように深く突き刺さった。

![Glyphs 公式『なぜ Glyphs には Windows 版がないのか』原文](https://raw.githubusercontent.com/Des-Magmeta/des-magmeta.github.io/main/src/content/posts/2026-03-06/ja/glyphs-no-windows_ja.jpeg)  

声明に記された一見立派な理由は、Windows ユーザーの目には単なる言い訳に映る。「私たちは一般的にクロスプラットフォーム化を否定しませんが、現時点では経済的に実現不可能に思えます」という公式声明は、明らかに荒唐無稽だ。周知の通り、世界のパソコン市場の 80% 以上をWindows が占め、その使用率は Mac を明らかに上回っている。公式の仮定「たとえすべてのリクエストがライセンスの販売に繋がったとしても」に従えば、莫大な利益を得られるはずだ。公式が「販売で開発やサポートの追加費用を賄うことはできません」「年間数百ドルの収益を期待するために６桁の金額を投資しなければなりません」と主張するのは、明らかに市場需要への意図的な無視であり、ユーザーの選択に対する粗暴な否定に他ならない。

さらに、業界を少しでも知る者なら、現代におけるクロスプラットフォーム開発がもはや夢物語ではないことを理解している。デザインソフトからオフィススイートまで、無数の製品が Windows と Mac システムの完全な互換性を実現している。フォントデザインソフトの中でも、FontCreator の公式開発元 High-Logic は [2024 年９月に Mac 版をサポートすると発表した](https://www.high-logic.com/zh/news/fontcreator-for-macos-released)（従来は Windows 版のみ）。これに対し、Glyphs は未だに Windows 版を提供しておらず、Glyphs を使いたい Windows ユーザーにとっては、埋めようのない残念な点と言わざるを得ない。

![FontCreator は公式に 2024 年９月に Mac 版をサポートすると発表した](https://raw.githubusercontent.com/Des-Magmeta/des-magmeta.github.io/main/src/content/posts/2026-03-06/fontcreator-supports-mac.jpeg)  

なぜ Glyphs だけが「特別扱い」を好むのか？結局のところ、根っからの傲慢さが原因だ。記事の中で彼らは「タイプデザインは Mac のビジネスです」と誇らしげに宣言しているが、Windows ユーザーがFontCreator・FontLab・FontForge などのソフトでフォントを作成している現実を見れば、この言葉の裏に Glyphs 公式の傲慢な態度がにじんでいることに気づくだろう。Mac はすでに Glyphs 公式の精神的トーテムと崇拝の対象となっており、Mac ユーザーという小さなコミュニティに閉じこもり、「エリートツール」という虚偽の栄光に浸ることを選び、Windows でデザインする愛好家やデザイナーにサービスを提供しようとしない。まるで Windows ユーザーはハイエンドなフォントデザインの世界に足を踏み入れる資格すらないかのように。このようなユーザー層の「階級分け」は、Windows ユーザーの選択を粗暴に否定するだけでなく、Glyphs が「アップル信者」の金を稼ぎつつ、大衆へのサービス責任は負いたくないという本性を露呈している。**まさに典型的な「両立を望む」姿勢だ**。

おそらくタイトルを見た瞬間、Mac を所有し Glyphs を使っているユーザーの中には、私の考えに疑問を抱いた方もいるだろう。「Glyphs に Windows 版がないなら、他のソフトを使えばいいのでは？」という疑問だ。私の見解では、どのソフトウェアにもそれぞれ特徴があり、他ソフトでは実現できない（あるいは同等の体験感を得られない）独自機能がある。これは単に別のソフトに切り替えるだけで解決できる問題ではない。

否定できないのは、Glyphs が Mac プラットフォームで確かに優れた成果を上げていることだ。その強力な機能と「スマートコンポーネント」などの効率的な編集を可能にする特徴により、多くのユーザーを獲得している。しかし、これが Windows ユーザーを無視できる理由にはならない。何しろ世界のパソコン市場では Windows システムが絶対的な主導権を握っており、その中にはフォントデザインを愛し、プロフェッショナルなツールを渇望する愛好家が大勢存在する。彼らは業界に足を踏み入れたばかりの初心者かもしれない。フォントデザインへの情熱を胸に抱きながらも、Glyphs の「システム差別」にただ嘆息するしかない。あるいは経験豊富なデザイナーかもしれない。Windows システムの操作ロジックに慣れ親しんでいるのに、たった一つのソフトのためにデバイスを買い替え、追加コストを強いられる。これは広大な Windows ユーザーにとって、明らかに不公平な扱いである。Glyphs 公式が「Windows 版を求める人に Mac を配布する方が、実際に Windows 版を制作・管理・維持するよりも安く済むということです」と主張する逆説的な言い分は、彼らの根底にある傲慢さを隠すための言い訳に過ぎません。

タイトルが示す通り、Windows システムを使用し、Glyphs を熱望しながらも利用できないアマチュアフォント愛好家として、公式声明を読み終えた私は到底納得できません。説明というより「言い逃れ」に過ぎません。多くのデザイナーや愛好家が私と同じく、Glyphs のこのような行為を「決して許せない」と思っているのではないでしょうか？Glyphs のやり方は Windows ユーザーの心を深く傷つけただけでなく、フォントデザイン業界全体を後退させています。フォントデザインは本来、オープンで包容力のある分野であるべきです。異なるシステムやツールにもそれぞれ価値があるはずです。しかし Glyphs は人為的に障壁を設け、Windows ユーザーを排除すると同時に、自らも Mac という狭い枠に閉じ込めています。このような短視的な行為は、フォントデザイン界をますます閉鎖的にし、最終的には業界全体の革新と進歩を阻害するだけです。

フォントデザインを始めたい Windows ユーザーにとって、Glyphs の「不在」は埋めようのない欠落だ。機能限定のツールの中から苦労して選ぶか、歯を食いしばって高額な Mac を購入するかの二択しかない。大半の人は私と同じように前者を選び、様々なソフトウェアで苦労しながら進んでいる。この無念さと喪失感は、Glyphs には永遠に理解できないだろう。私は思わず Glyphs 公式に問いたい：

**その傲慢さはいつまで続くのか？いつになったら身構えるのをやめ、真にユーザーの声を聞き、Windows ユーザーにも同等に優れたフォントデザインツールを提供してくれるのか？**

フォントデザインの魅力は、境界を越えて文字の美しさを表現し、感情や思想を伝える点にある。この魅力は、システムの壁によって縛られるべきではない。ここに Glyphs に対し、一日も早く目を覚まし、「システム差別」という枷を打ち破り、オープンで包容力ある姿勢で、フォントデザインを愛する全てのクリエイターを迎え入れるよう強く勧める。結局のところ、より多くの人々が参加してこそ、フォントデザイン業界は真に活気を取り戻すことができるのだ。

~~Glyphs が Windows 版の開発を一日でも諦めない限り、私は永遠に『なぜ Glyphs には Windows 版がないのか』を許せない！~~
